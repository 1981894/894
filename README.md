상품판매를 위한 랜딩페이지(카탈로그) 

링크 : https://1981894.github.io/894/

관리자는 상품등록 및 삭제, 수정이 가능합니다.
등록된 상품은 구축한 서버에 저장되며
링크가 있는 모든 사용자(pc, 모바일 모두)에게 보여집니다.
상품 등록시 제품의 가격, 카테고리, 상품명 입력이 가능하고,
썸네일사진과 상세내용, 상세페이지에 들어갈 이미지 업로드가 가능합니다.
제품 등록시 각 카테고리별로 상단에 고정할 수 있는 기능이 있습니다. 이 기능을 활용하면 새로운 품목이 등록되어도 밀려나지 않고 1페이지 상단에 고정됩니다.
관리자는 관리자페이지 뿐만 아니라 각 제품 카테고리 화면에서도 상품등록을 바로 진행할 수 있습니다. 제품의 상세페이지 내부에서는 수정버튼을 눌러 바로 수정도 가능합니다.

상품 카테고리는 아래의 6가지로 구성되어 있습니다.
순금제품, 아기제품, 목걸이, 귀걸이, 팔찌, 반지

각 제품 카테고리는 메인화면 및 좌측상단 햄버거 메뉴를통해 상품열람이 가능합니다.

각 제품 카테고리당 1페이지당 12개까지 보여지며, 갯수가 넘어가면 페이지가 넘어가며 하단에 페이지 선택이 가능합니다.

시력 보호를 위해 모든 화면에서 라이트모드와 다크모드 전환이 가능합니다.

제품선택 시 제품의 상세페이지 화면이 보여집니다. 위에서부터 제품 대표사진, 상품명, 판매가격, 상세설명, 상세이미지 순으로 보여집니다.

다양한 정보 제공을 위해 공식 SNS 바로가기 메뉴를 햄버거메뉴 하단에 추가하였습니다.

사용자는 상품 카테고리 내에서 검색어 입력을 통해 원하는 상품을 찾을 수 있습니다.
